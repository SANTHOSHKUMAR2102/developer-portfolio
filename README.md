# Santhosh Kumar — Portfolio

A responsive personal portfolio built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Profile copy, skills, and project entries are in `src/main.tsx`. Styling is in `src/style.css`.

Before public sharing, add actual project screenshots and approved public project links. Project artwork currently illustrates areas of work. GitHub and LinkedIn open in new tabs; the email link opens the visitor’s email app.
